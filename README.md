# CroqFruit

Page d'accueil du site de livraison de fruits et légumes CroqFruit — un primeur qui achète ses produits auprès de producteurs et les livre directement chez les particuliers.

## Contenu

- `index.html` — page d'accueil (HTML/CSS autonome, aucune dépendance de build)

## Aperçu local

Ouvrez simplement `index.html` dans un navigateur.
